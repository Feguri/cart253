# Color Stripes

Felipe Paiva

[View this project online](./index.html)

## Description

Store 5 to 8 colors in an array and draw them as vertical stripes across the canvas. Clicking cycles which color is “selected” and highlights that stripe, and pressing a key swaps two colors or reverses the array.
