# Bouncing ball with edge detection

Felipe Paiva

[View this project online](URL_FOR_THE_RUNNING_PROJECT)

## Description

 * Bouncing ball with edge detection!
 * A circle bounces across the canvas on its own, and when it hits an edge, it changes direction. and if statement is used to assess whether or not the ball has hit a boundary, and from which direction.
