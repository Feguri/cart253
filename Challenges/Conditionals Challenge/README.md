# Puck back hot and cold

Felipe Amorim & Felipe Paiva

[View this project online](URL_FOR_THE_RUNNING_PROJECT)

## Description

In this project, whe made it so the puck is pushed through the mouse and has to reach a target. The target turns black when the puck reaches it, and the puck changes colors based on the distance from the target.
